# Quiz Bot [Название под вопросом]

Квиз бот, пользователь задает количество вопросов,
в будущем (планируется) - категорию, из которой берутся вопросы.
Ответ выбирается из предложенных вариантов, 
за правильные ответы набираются баллы, 
таким образом определяется личный счет (рекорд) и место пользователя в доске лидеров.

## Текущие задачи
на старте проекта реализовать базовую функциональность.
Класс,  в рамках которого реализуете взаимодействие с пользователем
Почти полноценный будущий бэкенд для приложения: сервисы, хранилки, интерфейсы + реализации и т.д.


## Примерный диалог
Юзер: Начать игру

Бот: Сколько вопросов

Юзер: n

Бот: Хотите выбрать категорию вопросов или играть в разнобой?

Юзер: В разнобой

Бот: Q1 Варианты ответов: 1, 2, 3, 4

Юзер: 1

Бот: Вы ошиблись! Верный ответ: 2, +0 очков

Бот: Q2 варианты ответов 5, 6, 7, 8

Юзер: 6

Бот: Вы ответили правильно!  +10 очков

## Application
Тут находится все взаимодействие. Что должно случиться, когда юзер пользуется ботом.

### Способы взаимодействия
- Проходить квиз
- Смотреть таблицу лидеров

### Квиз
Описание процесса, при игре в квиз
```
начать ссесию               (1)
      ↓
узнать количество вопросов  (2)
      ↓
найти вопросы               (3)
      ↓
отправить вопросы           (4)
      ↓
получить ответ              (5)
      ↓
проверить ответ             (6)
      ↓
посчитать очки              (7)
      ↓
обновить ссесию             (8)
      ↓
сохранить результат         (9)
      ↓
вернуть результат           (10)
```
### Варианты разбиения на классы

#### StartQuis
Этот класс для инициализации и начала игры, то есть шаги (1) - (3).
Так же в него будет стартовать сессия.
Здесь будет жить функция getQuestion, пользуется правилом, что 1 user должен видеть разные вопросы.
```
"Мне нужно начать игру для пользователя X,на 5 вопросов."
        ↓
QuestionRepository → дай 5 вопросов
        ↓
QuizSession → создай игру
        ↓
QuizRepository → сохрани игру
        ↓
верни первый вопрос
```


#### AnswerQuestion
Этот класс отвечает за все действия с вопросами, то есть (4) - (8).
```
получить текущую сессию
        ↓
получить вопрос
        ↓
передать ответ в Domain
        ↓
получить correct / incorrect
        ↓
обновить Quiz
        ↓
сохранить Quiz
        ↓
вернуть результат

```

#### FinishQuiz
Этот класс сохраняет результат квиза (9)-(10) и завершает квиз, также может отвечать
за экстренный выход пользователя из игры(по кнопке в боте или по ошибке соединения)

### Смотреть таблицу лидеров
```
получи игроков
      ↓
отсортируй по очкам
      ↓
определи rank
      ↓
верни top игроков и место юзера
```
#### GetLeaderboard
Класс отвечает за этот процесс
