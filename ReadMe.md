# Quiz Bot [Название под вопросом]

Квиз бот, пользователь задает количество вопросов,
в будущем (планируется) - категорию, из которой берутся вопросы.
Ответ выбирается из предложенных вариантов, 
за правильные ответы набираются баллы, 
таким образом определяется личный счет (рекорд) и место пользователя в доске лидеров.

### Примерный диалог
Юзер: Начать игру

Бот: Сколько вопросов

Юзер: n

Бот: Хотите выбрать категорию вопросов или играть в разнобой?

Юзер: В разнобой

Бот: Q1 Варианты ответов: 1, 2, 3, 4

Юзер: 1

Бот: Вы ошиблись! Верный ответ: 2, +0 очков

Бот: Q2 варианты ответов 5, 6, 7, 8

Юзер: 6

Бот: Вы ответили правильно!  +10 очков

## Frontend
Реализуется Tg Mini App
Возможные действия пользователя: 
login / start / quiz / leaderboard / help

Одна из возможных задач на будущее - проверка прав пользователя (игрок/админ)

## Backend
База данных:
*   questions - база вопросов с айди, варианты ответов на них, правильный ответ.
*   leaderboard - отсортированный по убыванию набранных очков список пользователей.
* В будущем users: например, чтобы вести учет увиденных пользователем вопросов
* В будущем admins: для сверки полномочий

## API и архитектура
FE будет взаимодействовать с BE через BFF, задачи которого: обработка и передача запросов FE в BE в удобном виде и наоборот.
API обсуждается. 
Для передачи данных между FE, BFF, BE планируется использовать формат JSON

Проверка правильности ответа и подсчет очков будет совершаться на BE для защиты данных.

### Получение вопроса
При дальнейшем планировании возможны редакции.
#### FE -> BFF -> BE

```json
{
  "questions_count": 5
}
```
Роль пользователя (если появится) планируется определять на уровне BFF/BE
#### BE -> BFF

```json
{
  "questions": [
    {
    "question_id": 10,
    "question_text": "Some question",
    "answers": [
      "1",
      "2",
      "3",
      "4"
    ],
    "correct_answer": "3"
    },
    ...
  ]
}
```

#### BFF -> FE
```json
{
  "questions": [
    { 
      "question_id": 10,
      "question_text": "Some question",
      "answers": [
        "1",
        "2",
        "3",
        "4"
      ]
    },
    ...
  ]
} 
```
### Отправка ответа и оценка его правильности
#### FE -> BFF -> BE

```json
{
  "question_id": 10,
  "given_answer": 3
}
```
#### BE -> BFF

```json
{
  "correct": true,
  "points_earned": 10,
  "current_score": 30
}
```
